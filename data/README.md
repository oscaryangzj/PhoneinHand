# 数据说明

所有原始 CSV 按来源集中存放，每个录制文件只保留一份。`index.json` 记录路径、来源、标签、行数和 R10 用途。

| 来源目录 | 总录制数 | R10 训练 | R10 验证 | R10 未使用 |
|---|---:|---:|---:|---:|
| `smartrotate/` | 72 | 72 | 0 | 0 |
| `other/` | 226 | 97 | 47 | 82 |
| 合计 | 298 | 169 | 47 | 82 |

`smartrotate/` 对应原项目的 SmartRotation 数据组，文件名为 `imu_rotation_*`。`other/` 为 PhoneInHand 采集等其他来源，文件名为 `imu_inhand_*`。这是来源分类，不是模型的二分类标签。

## R10 的固定划分

`splits/R10.json` 按完整 recording 指定训练和验证，保留原 R10 名单和训练组顺序。同一录制不跨训练、验证。额外的 82 份录制保留供后续使用，不自动加入 R10；其中包括历史未采用/排除的数据和 R10 之后采集的数据。

## 预处理

每个录制按时间戳裁掉最初 3 秒，之后在每个训练窗口/验证录制中忽略最初 60 帧的损失和指标；训练窗长 128，验证逐录制流式推理。原始 CSV 不裁剪，裁剪数据在运行时生成于 `PhoneInHand/runs/`。

旋转增强只用于训练，先在物理单位下对 acc/gyro 使用同一个 SO(3) 矩阵，再归一化。固定复用 `models/R10/norm_stats.json`，不利用验证集重新拟合统计量。

## 标签

`hold_state` 是训练标签：`non_handheld=0`、`handheld=1`。项目判断手机是否完全离开支撑面；手握手机但仍接触桌面的 `desk_gripped` 属于 `non_handheld`，完全离开桌面的 `free_gripped` 属于 `handheld`。历史场景名称和其他已存在标签沿用原 R10 数据。

三种旧中文接触场景的 `scene_tag` 统一改为“桌面微动”，旧文件名保留以维持录制身份。文件名可能仍包含旧场景文字，**以 CSV 内的 `scene_tag` 为准**。这次合并只影响场景展示和分组统计，不改变二分类标签。
